## V0.3 当前研究口径

1. 主体统计按指数分别计算；上证指数、中证1000、创业板指、科创50为正文核心观察对象，其余指数保留完整统计与事件明细。
2. D1为首次从均线上方跌到均线下方的候选日；连续D1/D2/D3三日收盘均在均线下方后，D3确认真跌破。
3. D3后每次“前一日仍在均线下方、当日Close重新≥MA”定义为候选R1；连续三日站上均线后，候选R1成为正式R1，第三日为R3；失败尝试不结束原周期。
4. 跌幅、持续时间等主要分布统一报告：中位、P75、P90、P95、P99。
5. P1继续采用D0价格锚：D0为D1前一交易日，P1为D1后第一次Close≥D0 Close。
6. 全文以“正文做集合比较与推理、底稿做完整查数”为主要呈现方式，避免把正式报告退化成逐指数数据库浏览器。

## 当前报告主要优化

- 真假信号：拆解D1→D2→D3与候选R1→R2→R3；新增穿越均线幅度、首次修复成功率、重复尝试和假信号后续路径。重点结论是“穿越幅度比单纯穿越更有信息”，且成长指数对弱穿越更不敏感。
- 跌幅深度：按“分布厚尾 → 等D3的成本/收益 → Peak→D1→D3→Trough风险分段 → 丙/趋势修复价格位置”形成完整推理链，并比较核心指数差异。
- 持续时间：区分D1→Trough、Trough→R1/R3、D1→R3与D1→P1三个时钟；MA20/MA25切换展示；P1极长尾使用分位层级非等距图避免压缩中位/P75/P90。
- 条件风险：改成“本指数基准 → D3短期强度 → 长期趋势背景 → 短期×长期组合 → MA20→MA25动态升级”的风险读取顺序。
- 跨指数传导：由矩阵浏览改为“同步共振还是延迟传导”的研究问题；结论以大盘同步簇、中证1000后确认和跨风格分离为主，不建立机械领先链。
- 研究概览：已按当前全部子页最新结论重新生成。
