# V0.2 正式研究版收敛 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不新增研究内容、不改变事件和数据口径的前提下，将当前V0.2 HTML收敛为正式研究报告：正文负责理解，底稿负责审计。

**Architecture:** 直接基于已冻结的当前审阅版HTML做结构化patch，不触碰原始数据、事件识别和生产pipeline。各页统一为“研究问题/核心结论 → 核心图表 → 简洁解释 → 方法边界 → 折叠底稿”，保留所有审计数据和现有交互能力。

**Tech Stack:** HTML/CSS/JavaScript, Python/BeautifulSoup（仅用于离线HTML patch和静态验证）。

## Global Constraints
- 不新增F3、Regime、稳健性检验、Breadth acceleration等V0.3研究内容。
- 不修改D1/D2/D3、R1/R2/R3、Peak、Trough、P1、甲1/甲2/甲3/乙/丙定义。
- 完成事件维持1505：MA20=804、MA25=701；进行中事件维持12。
- 不执行原始数据重抓、事件重算和正式生产流水线。
- 不采用严格篇幅预算，以可读性和研究完整性为准。
- 完整底表和审计字段不删除，改为默认折叠或工具视图。
