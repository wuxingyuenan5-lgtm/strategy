# 持续时间与条件风险分析优化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改变V0.2事件定义、1505个完成周期和原始数据的前提下，重构持续时间分析与条件风险分析，使动态时长风险和D3条件风险职责更清楚。

**Architecture:** 使用当前冻结的 `events.csv` 与现有HTML进行审阅版patch。新增统计仅为已有事件字段的派生汇总，不重新抓取数据、不重跑事件识别。持续时间页承接动态生存/未修复分析；条件风险页聚焦D3时点已知变量和后续趋势升级。

**Tech Stack:** Python 3.12, pandas/numpy, inline HTML/SVG。

## Global Constraints
- 不改变D1/D2/D3、R1/R2/R3、Peak、Trough、P1、甲1/甲2/甲3/乙/丙定义。
- 不改变1505个完成周期与12个进行中事件。
- P1仅解释为“D1价格首次收复/首次触及”，不解释为稳定价格修复。
- “已持续X日仍未R3”归入持续时间分析，不再作为D3初始条件。
- 条件风险必须区分D3即时变量与后续路径升级变量。
