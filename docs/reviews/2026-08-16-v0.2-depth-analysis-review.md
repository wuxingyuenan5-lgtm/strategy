# V0.2 跌幅深度分析｜审阅优化记录

日期：2026-08-16
分支：`agent/ma-breakdown-v0.2`

## 本轮边界

本轮不修改任何事件识别或数据口径：D1/D2/D3、R1/R2/R3、Peak、Trough、P1、甲1/甲2/甲3、乙、丙定义均保持不变；完整周期仍为1505个，进行中事件仍为12个。

本轮仅重构“跌幅深度分析”页面的研究组织与展示。

## 已确定优化

1. 保留MA20/MA25完整宽表和横向滚动能力，不为屏幕宽度删除统计字段。
2. 删除正式报告中所有“请横向滚动”“为适配屏幕”等操作性/开发性辅助说明。
3. 风险分位统一命名为“风险P75 / 风险P90 / 风险P95 / 风险P99”。其中风险P90表示约10%的历史事件最终跌幅更差。
4. 标准差、概率、正值率等无方向比例不再显示“+”号；收益、跌幅等有方向变量继续保留正负号。
5. 新增甲1/甲2/甲3风险分位带，突出中位数到P90/P95/P99的厚尾扩张。
6. 将“三日确认”改为同时观察确认收益与确认成本：甲1→甲3剩余风险收敛、D1→D3价格变化、甲1/甲3风险P90。
7. 新增Peak→D1→D3→Trough路径拆解，区分信号出现前已经发生的回撤、三日确认成本和D3以后剩余风险。
8. 指数风格分析由均值主导改为Median + 风险P90/P95 + 乙跌超10%概率，并增加乙分位图。
9. 丙模块改名为“R1价格修复结果（R3确认后回看）”，强调其后视镜属性，并展示均值、中位、风险P10、正值率和极值。
10. MA20 vs MA25只做描述性比较；不把MA25更深/更久直接解释为参数因果，MA20→MA25升级效应留在条件风险分析。
11. 极端事件继续按乙从深到浅排序，新增市场阶段字段；跨指数共振解释留到条件风险/跨指数传导页面。

- MA20：甲1/甲2/甲3中位约为 -4.0% / -3.1% / -2.7%；甲3风险P90约 -14.2%。
- MA25：甲1/甲2/甲3中位约为 -4.1% / -3.2% / -2.8%；甲3风险P90约 -16.0%。
- Peak→D1中位：MA20约 -3.25%，MA25约 -3.46%。
- D1→D3价格变化中位：MA20约 -0.74%，MA25约 -0.78%。
- 乙中位：MA20约 -7.73%，MA25约 -8.26%。
- 丙中位均接近0，但均值约 -2%，风险P10约 -10%，呈明显左尾。

以上数字均来自V0.2当前冻结事件数据，不引用V0.1.3旧结果。
