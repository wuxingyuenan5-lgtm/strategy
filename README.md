# Strategy Research

本仓库用于存档与持续迭代策略研究项目。

## 当前项目：均线有效跌破统计

**当前冻结基线：v0.1.3**  
**基线冻结日期：2026-08-16**  
**研究数据截止：2026-07-31**

本项目研究 A 股主要指数发生“有效跌破”后，在重新站回对应均线前的下行深度、确认后的剩余下跌、收回时盈亏、持续时间，以及市场宽度/多指数共振对风险的影响。

### 当前研究范围

- 7 个 A 股指数：上证指数、沪深300、中证1000、创业板指、科创50、中证全指、中证红利
- 均线：MA20 / MA25
- 信号确认：连续 3 个交易日收盘位于均线下方
- 三种统计方案：方案甲 / 乙 / 丙
- 当前有效跌破事件总数：1,605 次（MA20 + MA25）

### v0.1.3 当前核心结论

1. 有效跌破后的风险分布具有明显厚尾；方案甲全样本中位最大跌幅约 -3.2%，平均约 -5.5%，P95 约 -18.6%。
2. 市场阶段的解释力明显高于 MA20 与 MA25 的差异；2008 危机期与 2019–2021 结构牛阶段的跌破后风险深度差异约 5 倍。
3. MA25 相比 MA20 更慢、事件略少、跌幅略深，但差距总体有限。
4. 连续三日确认能够过滤部分假跌破，但平均消耗约 1.2 个百分点的下跌空间。
5. 跌破持续时间与下跌深度具有较强相关性，MA20/MA25 样本相关系数均约 0.75。
6. 跨指数风险表现为“分层同步”，不宜依赖单一领先指数。
7. Day3 确认时相对均线的偏离深度，是当前研究中较稳定的条件风险分层变量。
8. 单指数跌破与多指数共振的风险性质不同；当核心指数均线下方广度显著扩大时，后续跌幅和修复时间整体恶化。

### 数据口径特别说明

中证全指统一使用正式指数代码 **000985.CSI**。当前可审计连续原始序列仅覆盖 2011-08-02 至 2015-04-07；由于 MA 事件识别依赖连续路径，v0.1.3 不对缺失区间做插值、代理或跨期硬拼接。
